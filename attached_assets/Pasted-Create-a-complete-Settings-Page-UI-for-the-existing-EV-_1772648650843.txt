GENERAL SETTINGS PAGE LAYOUT

The Settings page should include the following sections:

1️⃣ Profile Settings (All Roles)

Display:
- Full Name
- Email
- Phone Number

Buttons:
- Edit Profile
- Change Password

Data source:
users collection

========================================

2️⃣ Vehicle Profile (EV Users Only)

Show only if role === "ev_user"

Display:
- Vehicle Model
- Registration Number
- Battery Capacity
- Preferred Connector Type
- Preferred Power

Data source:
users.vehicleProfile

Buttons:
- Edit Vehicle

========================================

3️⃣ Payment Settings (All Roles)

Display:
- Default Payment Method
- Saved Payment Methods
- Billing History

Buttons:
- Add Payment Method
- View Transactions

========================================

4️⃣ Notification Preferences (All Roles)

Display toggle options:

- Booking confirmation notifications
- Charging reminder notifications
- Station availability alerts

Buttons:
- Save Preferences

========================================

5️⃣ Location Preferences (All Roles)

Display:

- Default city
- Station search radius

Buttons:
- Update Location

========================================

6️⃣ Security Settings (All Roles)

Display:

Buttons:
- Change Password
- Logout from all devices

========================================

7️⃣ Station Settings (Owner Only)

Show only if role === "owner"

Display:

- Business Name
- Station Address
- Operating Hours
- Connectors
- Pricing

Buttons:
- Edit Station
- Manage Connectors

Data source:
stations collection

========================================

8️⃣ Admin Settings (Admin Only)

Show only if role === "admin"

Display:

Firebase Status
Database Tools

Buttons:
- Seed Sample Data
- Clear Stations

Also show platform statistics:

- Total Stations
- Total Users
- Total Bookings
